Nexus v32 — 사전 배포 로컬 검증 결과
검사일: 2026-10-29

확인 완료
- 70개 HTTP/API 기능 검사: 메인 및 경로 별칭, 회원가입, 관리자 로그인, 관리자 메뉴 5개, 고객 문의/답변,
  문의 미확인 수, 상담 종료/재개, 접근 권한, CSRF 차단, 서버 재시작 후 데이터 보존
- 운영 모드 검사: 비밀키/영구 저장소/관리자 비밀번호 누락 시 안전한 시작 실패,
  관리자 계정 최초 1회 생성, 비밀번호 해시 저장, 재시작 후 계정 중복 생성 방지
- 총 25개 인라인 JavaScript 스크립트 구문 검사 통과
- render.yaml 문법, 관리자 초기 설정, 영구 디스크/상태 확인 엔드포인트 설정 검사 통과
- 관리자 초기 비밀번호, 비밀번호 해시, 운영 DB, .env 파일이 ZIP에 들어가지 않도록 제외
- /healthz는 SQLite DB까지 확인하도록 개선함

검증 범위 밖
- 실제 Render에 공개 배포된 서버의 실사용 검증 (아직 배포되지 않음)
- 기존 Netlify 주소에서 Python 서버 구동 여부 (Netlify Drop에서는 Python 서버가 실행되지 않음)
- 실제 사용자 기기에서 JavaScript 클릭 및 모바일 표시 (브라우저 자동 테스트는 실행 환경 접근 차단)
- Discord 봇 실제 설치/초대 결과

테스트 명령어
python tests/smoke_test.py
python tests/check_production.py

반드시 입력해야 하며, 실제 비밀번호는 ZIP에 담겨 있지 않습니다.
